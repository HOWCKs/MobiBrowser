Prévia de interface

Não é o app: é o layout, as cores, os textos e o movimento do código Compose renderizados em HTML para revisar no celular em 1 segundo, sem CI. Toques funcionam.

Se você mexer no ui/ e esquecer disto aqui, a prévia desanda — o arquivo declara os tokens de onde copia.

O que isto NÃO é. Não há como rodar @Preview do Compose nem gradle no Code on the Go: falta JDK, Android SDK, layoutlib e aapt2 (binários que não executam no Android). O APK continua nascendo só no GitHub Actions. O ganho aqui é outro: revisar hierarquia, textos, estados vazios e fluxo de toque antes de gastar o ciclo de compilação.

Como atualizar a prévia: git pull e abrir este arquivo de novo. Ela mora no repositório em tools/preview/index.html.
